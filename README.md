# Дожить до рассвета

Мини-игра в Telegram: пять минут выживания против зомби. Доход приносят реклама Adsgram и покупки за Telegram Stars.

## Запуск за час

### 1. Бот
1. В [@BotFather](https://t.me/BotFather) отправь `/newbot` и сохрани токен. Никому его не пересылай.
2. Узнай свой числовой ID у [@userinfobot](https://t.me/userinfobot). Он нужен для команды `/stats`.

### 2. Сервер на Render
1. Загрузи эту папку в **приватный** репозиторий GitHub.
2. На [render.com](https://render.com): **New → Blueprint**, выбери репозиторий. Render прочитает `render.yaml`.
3. Render спросит значения. Заполни:
   - `BOT_TOKEN` — токен из шага 1;
   - `ADMIN_ID` — твой числовой ID;
   - `SUPPORT_CONTACT` — например, `@твой_ник`;
   - `APP_LINK` — пока оставь пустым;
   - `ADSGRAM_BLOCK_ID` — пока оставь пустым.
4. Дождись статуса **Live** и скопируй адрес вида `https://zombie-night-xxxx.onrender.com`.

Цена по схеме из `render.yaml`: около $13 в месяц ($7 сервер + $6 база). Бесплатный тариф подходит только для пробы: сервер засыпает после 15 минут без запросов и просыпается около минуты, а бесплатная база перестаёт работать через 30 дней.

### 3. Мини-приложение
1. В BotFather отправь `/newapp`, выбери бота, укажи название, описание и картинку 640×360.
2. Web App URL — адрес с Render. Короткое имя — например, `night`.
3. Получишь ссылку `https://t.me/имя_бота/night`. Впиши её в `APP_LINK` на Render (Environment) и сохрани.

Проверь: открой бота, нажми `/start`, сыграй, купи самый дешёвый набор, отправь `/stats`.

### 4. Реклама Adsgram
1. Зарегистрируйся на [partner.adsgram.ai](https://partner.adsgram.ai), добавь приложение и создай блок формата Reward.
2. На Render открой Environment и скопируй значение `ADSGRAM_SECRET`.
3. В настройках блока укажи Reward URL:
   `https://АДРЕС_С_RENDER/adsgram/reward?userid=[userId]&secret=ADSGRAM_SECRET`
4. Числовой ID блока впиши в `ADSGRAM_BLOCK_ID` на Render.

Пока блок не настроен, игра работает без рекламы: кнопки воскрешения и удвоения скрыты.

## Деньги
- **Stars.** Звёзды копятся на балансе бота и выводятся в TON через Fragment. Вывод доступен спустя время после покупки; актуальные сроки и минимум смотри в разделе баланса бота.
- **Adsgram.** Доход и выплаты видны в кабинете партнёра.
- **Налоги.** С дохода нужно платить налог. Для начала обычно подходит самозанятость, но вывод через криптовалюту лучше заранее обсудить с бухгалтером.

## Что где менять
- Цены, награды, лимиты: `app/game.py`.
- Врагов, перки, графику, экраны: `static/index.html`.

## Управление
- `/stats` — игроки, активность и звёзды, только для `ADMIN_ID`.
- `/paysupport` и `/terms` — поддержка и условия для покупателей.

## Проверка
```
pip install -r requirements-dev.txt
pytest -q
```
Тесты поднимают настоящий сервер с подставным Telegram API и SQLite. Без `DATABASE_URL` игра тоже хранит данные в SQLite, это режим для компьютера, а не для Render.

## Защита
- Каждый запрос проверяется подписью Telegram initData.
- Монеты, цены и покупки считаются только на сервере.
- Платёж начисляется один раз, возврат звёзд списывает набор.
- Длительность забега ограничена часами сервера, число убийств и награда имеют потолок. Полностью исключить накрутку в браузерной игре нельзя, поэтому потолки можно ужесточить в `app/game.py`.

Секреты храни только в Environment на Render. Файла `.env` в репозитории быть не должно.
